# Amber Leaf · Brewed in Smoke

Landingspagina voor de fictieve theecampagne *Amber Leaf · Brewed in Smoke*.
Schoolopdracht Creative Automation, Artevelde Hogeschool (Senne Cera, DVG2).

- `index.html` + `style.css`: statische pagina (hero met video, verhaal, collectie Nº01–Nº04, ritueel, archief-formulier).
- `img/`: AI-beelden (Adobe Firefly) en hero-video; `img/mail/` beelden voor de MailerLite-mails.
- Het formulier is een MailerLite embedded form ("Open het archief").

Live via GitHub Pages: https://senneeeeeeec.github.io/amber-leaf/
